# 神釣手 Best Angler — 2D 高畫質重製版（線上版）

官方接手後，內容與修改方向以官方決定為準。

**線上遊玩：** https://jhou12345600-lang.github.io/bestangler/

## 功能

- 帳號註冊／登入。帳號為 4–16 個英文、數字或底線，密碼至少 6 碼，信箱選填。
- 新手馬上玩：免註冊的訪客身分，之後可以綁定成正式帳號，進度保留。
- 雲端存檔：換裝置登入同一個帳號，就能接著玩。
- 連線：
  - 線上玩家名單
  - 同一個釣池會一起站在碼頭上，看得到彼此的浮標和搏魚
  - 表情互動
  - 全服漁獲通知
  - 全服排行榜
- 4 個釣池、13 種魚，有拋竿、咬餌、揚竿、捲線搏魚、上岸結算。另有釣具店與裝備系統。
- 大碼頭：每個釣池的碼頭可以容納很多玩家。
  - 拖曳水面或點上方的碼頭地圖，可以沿著碼頭看其他人釣魚。
  - 按左右「走動」鈕（或鍵盤 ← →）走到別的位置釣魚。
- 水下搏魚：揚竿中魚後，整場搏魚都在水下鏡頭進行。
  - 魚離得越近看起來越大，遠的魚會隱入水色。
  - 釣線會依張力變色、抖動，也看得到水草、湖底揚沙和氣泡。
  - 「看水面／看水下」可以切換鏡頭，遊戲會記住你的選擇。
- 角色：可選女主角或男主角。在大廳點「換角色」或點頭像更換。
- 聊天：
  - 分成世界頻道和本池頻道。
  - 同池玩家說的話會顯示在頭上。
  - 有簡單的不雅字過濾，也可以封鎖特定玩家。
- 好友：
  - 可以用帳號加好友，或在碼頭點玩家名字、從線上名單加好友。
  - 好友名單會顯示對方在線狀態和所在釣池，可以直接「前往」。
- 送禮：好友之間可以互送禮物，每人每天最多送 10 次。
  - 可以送銀幣（每次最多 1,000）、金幣（每次最多 20）、魚餌（每次最多 100 個）。
  - 也可以送釣竿、釣線、浮標、假餌。正在使用中的裝備不能送。

## 官方企劃規格（2026/10/26 加入）

依官方提供的《神釣手之進擊的戰鬥池 遊戲企劃 SPEC》與數值表調整：

- **等級與稱號**：
  - 99 級經驗值表照官方公式計算。
  - 13 個稱號，從初級新手到宗師十段。
- **魚種數值**：
  - 每個尺寸區間各有魚力值、體力值和經驗值。
  - 重量照「尺寸重量對照表」計算。
  - 銀幣依「回魚費」公式計算。
  - 采金魚另外給金幣。
- **魚池**：
  - 休閒池 Lv1：可下注，每竿收銀幣等於下注額。
  - 競技池 Lv3：每竿收 1 金幣。
  - 路亞池 Lv5：每 10 分鐘收 100 金幣。
  - 戰鬥池 Lv7：每 10 分鐘收 1000 金幣。
  - 等級不足時無法打開魚池面板。
- **釣具**：
  - 釣竿決定拋投距離、釣線長度和可釣到的魚體上限。
  - 釣線有承受力和生命值，生命值是可以拋投的次數。
  - 浮標分三種敏感度。
  - 魚餌一包 10 份，各魚餌對每種魚有官方釣獲率。
- **釣魚**：浮標震動後 3 秒內要揚竿，而且只有 30% 的機率鉤到魚。
- **采金魚**：
  - 休閒池每 100 竿會隨機出現 2~4 尾。
  - 其他池每 60 分鐘最多 12 尾。
- **搏魚**：
  - 收線光條共 15 格，往上收線 10 格、往下放線 5 格。
  - 點一下「力」收一格，按住會持續往上收。超過 2 秒沒按，光條每秒自動降一格。
  - 釣力值 P + 魚力值 F 大於承受力 S 時，線會斷。
  - 魚的體力值每秒減少 P/10，減到 0 就釣起來了。
  - 線被拉完，或大約 7 秒沒收線，魚會跑掉。
  - 魚力值依「魚力值波幅」變化：大部分時間在中等，不時有怒火高峰；越接近釣起，高峰越小，最後變低。
- **水面與水下**：
  - 中魚後魚先在水面翻騰。超過 40 公分的魚才會進入水下畫面，背景用官方水下圖。
  - 水下時，魚一開始會潛到水底。衝刺時往左快游，沒力時往右緩游，沒體力後被拉到右上方水面。
  - 水面上，魚照官方圖以 8 字形游動。
  - 最後回到水面，角色用撈網把魚撈起來。
- **星等**：在體力值 ÷2、÷3、÷4、÷5 秒內釣起，分別是 2 到 5 顆星。
- **其他**：
  - 結算畫面只有「售出」。
  - 任務：每日登入、連續 7 天登入、第一尾魚、各池釣魚數、每日公斤挑戰、第一尾采金魚、全服最大紀錄魚。
  - 排行榜分週、月、總排名，並顯示「我的成績」。
  - 「儲值」與「幸運摸彩」目前只顯示說明，尚未開放。

## 檔案結構

| 路徑 | 內容 |
|---|---|
| `index.html` | 遊戲本體，單一檔案，Canvas 2D 加 WebGL 水面 |
| `assets.json`、`img/` | 素材索引與圖集（WebP） |
| `lib/` | Firebase JS SDK（compat 版） |
| `firebase-config.js` | Firebase 專案設定（公開的用戶端設定，不是密碼） |
| `database.rules.json` | Realtime Database 安全規則 |
| `dev/` | 開發用：素材建置與 AI 放大腳本、Firebase 模擬器設定。詳見 [`dev/HANDOVER.md`](dev/HANDOVER.md) |

## 架設到其他 Firebase 專案

1. 建立 Firebase 專案，新增網頁應用程式，把 `firebaseConfig` 填進 `firebase-config.js`。記得加上 `databaseURL`。
2. Authentication → 登入方式：啟用「電子郵件/密碼」和「匿名」。
3. Realtime Database：建立資料庫（建議新加坡區），把 `database.rules.json` 的內容貼到「規則」後發布。
4. 網站放在任何靜態主機都可以，例如 GitHub Pages、Firebase Hosting。

## 已知限制

- 帳號不使用真實信箱登入，所以無法線上自動重設密碼。
- 沒有遊戲伺服器，遊戲邏輯在玩家端執行，排行榜分數理論上可以被竄改。
- Firebase 免費方案最多約 100 人同時在線。
- 男主角是暫代美術，用 Microsoft Rocketbox 3D 人物（MIT 授權）算繪而成。官方可以換成自己的男主角美術。
- 女主角只有兩張靜態原圖，所以走路時用上下起伏表現，沒有走路動畫。
- 送禮和存檔都在玩家端處理。若要防作弊，需要加遊戲伺服器。
- 企劃中以下項目需要伺服器或金流，這一版沒有做：
  - 儲值（第三方金流）
  - 幸運摸彩實體獎品與出貨後台
  - 其他池采金魚的失敗機制與 JP 彩金池
  - 邀請碼
  - 點廣告賺金幣
  - 電腦版橫式版型
